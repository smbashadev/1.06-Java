# About

The **Java Programs** folder is a comprehensive collection of **112 Java programs** created for students, beginners, self-learners, and interview aspirants.

The programs are organized in a logical sequence, starting from basic Java syntax and progressing to methods, arrays, strings, operators, loops, patterns, matrix operations, and method overloading.

Each program follows professional coding standards and contains detailed comments to make learning easier.

---

# Learning Objectives

After completing these programs, you will be able to:

- Understand Java programming fundamentals
- Learn Java syntax and coding conventions
- Work with variables and data types
- Perform type casting
- Use operators effectively
- Accept user input using Scanner
- Work with conditional statements
- Use loops efficiently
- Solve number-based problems
- Print various star and number patterns
- Work with one-dimensional, two-dimensional, and jagged arrays
- Perform matrix operations
- Manipulate strings
- Understand String, StringBuffer, and StringBuilder
- Create and use methods
- Understand parameter passing and return types
- Learn method overloading
- Build beginner-friendly Java applications
