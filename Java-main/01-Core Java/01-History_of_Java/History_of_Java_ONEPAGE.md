# History of Java

Java is a high-level, object-oriented programming language developed at **Sun Microsystems** in the early 1990s. Its history began in **1991** with the **Green Project**, led by **James Gosling**, along with Mike Sheridan and Patrick Naughton. The original goal was not to create a web programming language, but to develop software for interactive consumer electronic devices.

The team created a programming language called **Oak**, named after an oak tree outside Gosling's office. Oak was designed to be simple, reliable, portable, secure, and capable of running on different types of hardware. When the consumer-electronics market did not develop as expected, the team looked toward the rapidly growing **Internet and World Wide Web**.

Oak was renamed **Java** in 1994 because the name Oak was already associated with another product. Java was publicly announced by Sun Microsystems in **1995**, and **JDK 1.0** was released in January **1996**. One of Java's major innovations was the **Java Virtual Machine (JVM)**. Java programs are compiled into **bytecode**, which can run on any system with a compatible JVM. This led to Java's famous principle: **“Write Once, Run Anywhere.”**

Java initially became popular through **Java applets**, which allowed interactive programs to run inside web browsers. Although applets eventually disappeared, Java found an even more important role in **enterprise and server-side software**. Technologies such as **JDBC, Servlets, JSP, and J2EE** helped Java become widely used for banking, business applications, web servers, and distributed systems.

Java continued to evolve through major releases. **Java 5 (2004)** introduced generics, annotations, enumerations, and enhanced `for` loops. **Java 8 (2014)** introduced lambda expressions and the Stream API, greatly improving functional programming capabilities. **Java 9 (2017)** introduced the module system. Oracle acquired Sun Microsystems in **2010**, becoming the primary steward of Java.

In recent years, Java has adopted a faster release cycle and modern language features. **Java 11 (2018), Java 17 (2021), Java 21 (2023), and Java 25 (2025)** are important Long-Term Support (LTS) releases. Modern Java includes features such as records, pattern matching, and **virtual threads**, making it suitable for high-performance and highly concurrent applications.

Today, Java is widely used in **enterprise software, web and cloud applications, financial systems, backend services, big-data technologies, and Android's historical ecosystem**. Its long-term success comes from its portability, strong ecosystem, backward compatibility, security, automatic memory management, and the powerful JVM.

**In short, Java evolved from a 1991 consumer-electronics experiment called Oak into one of the world's most influential programming platforms, largely because its JVM-based architecture solved the problem of running software across different platforms.**
